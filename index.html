Level 01 · Foundation

Antiderivatives

Differentiation takes a function and returns its slope. Integration runs it backwards: given the slope function f(x), find a function F(x) whose derivative is f(x).

\int f(x)\,dx = F(x) + C \quad where \quad F'(x) = f(x)

The constant matters. A constant vanishes when you differentiate, so x2, x2 + 1 and x2 − 7 all have slope 2x. The antiderivative is a whole family of parallel curves, and C selects one of them.

Basic formulas

Every derivative you already know is an integral formula read backwards. Two rules let you build larger answers from these pieces.

\int k\,f(x)\,dx = k\int f(x)\,dx \qquad \int [f(x) \pm g(x)]\,dx = \int f(x)\,dx \pm \int g(x)\,dx

Power rule drill

Rewrite first, then integrate

Problem 2\int \tan^2 x\,dx = \int (\sec^2 x - 1)\,dx = \tan x - x + C

Level 03 · Core techniques

Substitution

Substitution undoes the chain rule. When the integrand looks like f(g(x)) times g'(x), name the inside function u = g(x). Then g'(x) dx becomes du and the integral shrinks to a basic one.

\int f(g(x))\,g'(x)\,dx = \int f(u)\,du \quad with \quad u = g(x)

A shortcut worth remembering: when the top is the derivative of the bottom, \int \frac{f'(x)}{f(x)}\,dx = \ln|f(x)| + C.

Standard forms and completing the square

A handful of integrals involving x2 ± a2 turn up constantly. Learn the shapes, then use completing the square to force any quadratic into one of them.

The bell curve and its arctangent

Here f(x) = 1/(x2 + a2) in blue and its antiderivative F(x) = (1/a) tan-1(x/a) in amber. Change a and watch F flatten out.

Completing the square

Example A\int \frac{dx}{x^2+4x+13} = \int \frac{dx}{(x+2)^2+3^2} = \frac{1}{3}\tan^{-1}\frac{x+2}{3} + C

Level 05 · Advanced techniques

Partial fractions

A rational function P(x)/Q(x) with deg P < deg Q can be split into simpler fractions, one for each factor of Q. If deg P ≥ deg Q, divide first.

Distinct linear factors

\frac{px+q}{(x-a)(x-b)} = \frac{A}{x-a} + \frac{B}{x-b}

Repeated factor

\frac{px^2+qx+r}{(x-a)^2(x-b)} = \frac{A}{x-a} + \frac{B}{(x-a)^2} + \frac{C}{x-b}

Irreducible quadratic

\frac{px^2+qx+r}{(x-a)(x^2+bx+c)} = \frac{A}{x-a} + \frac{Bx+C}{x^2+bx+c}

Cover-up solver

Enter distinct a and b and the numerator px + q. To find A, cover the factor (x − a) and put x = a in everything else.

Two more

Distinct\frac{1}{(x-2)(x-3)} = \frac{-1}{x-2} + \frac{1}{x-3} \Rightarrow \int = \ln\Big|\frac{x-3}{x-2}\Big| + C
Repeated\frac{1}{x(x+1)^2} = \frac{1}{x} - \frac{1}{x+1} - \frac{1}{(x+1)^2} \Rightarrow \int = \ln\Big|\frac{x}{x+1}\Big| + \frac{1}{x+1} + C

Level 06 · Advanced techniques

Integration by parts

Parts undoes the product rule. Split the integrand into u and dv, then trade the hard integral for an easier one.

\int u\,dv = uv - \int v\,du

Pick u using ILATE: Inverse trig, Logarithmic, Algebraic, Trigonometric, Exponential. The function that comes first in the list is usually u.

A useful shortcut

Rule\int e^x[f(x) + f'(x)]\,dx = e^x f(x) + C
Example\int e^x(\sin x + \cos x)\,dx = e^x\sin x + C

Level 07 · Definite integrals

Area, Riemann sums and the Fundamental Theorem

The definite integral is the signed area between a curve and the x-axis from x = a to x = b. Add up thin strips and let them get thinner. The Fundamental Theorem says the limit is simply F(b) − F(a).

\intl{a}{b} f(x)\,dx = \lim_{n \to \infty} \sum f(x_i)\,\Delta x = F(b) - F(a)

Worked examples

Polynomial\intl{0}{2}(3x^2+1)\,dx = \ev{x^3 + x}{0}{2} = 10 - 0 = 10
Trig\intl{0}{\pi/2}\cos x\,dx = \ev{\sin x}{0}{\pi/2} = 1
Change limits\intl{0}{1}2x e^{x^2}dx: u = x^2 gives limits 0 to 1, so \intl{0}{1}e^u\,du = e - 1

When you substitute inside a definite integral, change the limits too, and you never need to go back to x.

Level 08 · Definite integrals

Properties of definite integrals

These properties turn long calculations into one-liners, and they are favourites in board papers.

Basic

\intl{a}{b}f(x)\,dx = \intl{a}{b}f(t)\,dt
\intl{a}{b}f\,dx = - \intl{b}{a}f\,dx
\intl{a}{b}f\,dx = \intl{a}{c}f\,dx + \intl{c}{b}f\,dx

Reflection (the King property)

\intl{a}{b}f(x)\,dx = \intl{a}{b}f(a+b-x)\,dx
\intl{0}{a}f(x)\,dx = \intl{0}{a}f(a-x)\,dx

Even and odd

\intl{-a}{a}f\,dx = 2\intl{0}{a}f\,dx \quad if f(-x) = f(x)
\intl{-a}{a}f\,dx = 0 \quad if f(-x) = -f(x)

Doubling the interval

\intl{0}{2a}f\,dx = 2\intl{0}{a}f\,dx \quad if f(2a-x) = f(x)
\intl{0}{2a}f\,dx = 0 \quad if f(2a-x) = -f(x)

Even, odd or neither?

The King property in action

Set upI = \intl{0}{\pi/2}\frac{\sin x}{\sin x + \cos x}\,dx
ReflectI = \intl{0}{\pi/2}\frac{\cos x}{\cos x + \sin x}\,dx \quad (replace x by \pi/2 - x)
Add2I = \intl{0}{\pi/2}1\,dx = \frac{\pi}{2}
AnswerI = \frac{\pi}{4}

Level 10 · Applications

Differential equations

A differential equation involves a function and its derivatives. The order is the highest derivative present, and the degree is the power of that highest derivative once it is free of roots and fractions. Solving one means integrating, and integration constants give a family of solutions.

Variable separable

\frac{dy}{dx} = f(x)\,g(y) \Rightarrow \int \frac{dy}{g(y)} = \int f(x)\,dx

Linear first order

\frac{dy}{dx} + Py = Q, \quad I.F. = e^{\int P\,dx}
y \cdot (I.F.) = \int Q \cdot (I.F.)\,dx + C

Slope field explorer

Each short segment shows the slope the equation demands at that point. Click or drag on the field to start a solution curve there.

Worked examples

Separable\frac{dy}{dx} = 2xy \Rightarrow \int \frac{dy}{y} = \int 2x\,dx \Rightarrow \ln|y| = x^2 + c \Rightarrow y = Ce^{x^2}
Linear\frac{dy}{dx} + \frac{y}{x} = x^2: \; I.F. = e^{\ln x} = x
Continue\frac{d}{dx}(xy) = x^3 \Rightarrow xy = \frac{x^4}{4} + C \Rightarrow y = \frac{x^3}{4} + \frac{C}{x}
